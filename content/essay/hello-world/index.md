写作这件事，停下来容易，重启很难。

很长一段时间里，我的想法都散在备忘录、聊天记录和各种临时文件里。当时觉得「记下了」，过几个月再回头看，只剩一堆断句，想不起前因后果。**碎片不等于记录。**

所以有了这里。不追热点，不做流量，就当一个能长期存活的抽屉：把值得留下的东西，按自己的节奏放进去。

## 打算写些什么

- **读书与技术笔记** —— 主要是我自己会回头查的内容
- **折腾记录** —— 踩过的坑，以及最后是怎么绕过去的
- **零散想法** —— 那些还没成形、但不想丢掉的念头

## 关于这个博客本身

整站是纯静态的，构建只需要一个 Hugo 二进制文件，没有数据库、没有服务端。文章是普通的 Markdown 文件，即使将来换掉主题，这些年写下的文字也**一个字都不会丢**。

{{< alert >}}
这也是我选它的主要原因：**内容比工具活得久**。
{{< /alert >}}

## 写作速查（写给自己看）

新建一篇文章：

```powershell
.\new-post.ps1 "文章标题"
```

本地预览（含草稿）：

```powershell
.\preview.ps1
```

写完推送到 GitHub，剩下的交给自动部署：

```powershell
git add -A
git commit -m "新文章"
git push
```

一篇文章的头部是这样写的：

```toml
+++
title = "文章标题"
date = 2026-10-14
draft = true          # 草稿不会发布，写完改成 false
description = "列表页和搜索里显示的摘要"
tags = ["标签一", "标签二"]
categories = ["分类"]
+++
```
